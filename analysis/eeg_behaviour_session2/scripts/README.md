# Kawaii study scripts

Run the study analysis from the installed `kawaii-session2-eeg` command. See
[`../README.md`](../README.md) and [`../docs/STUDY_ANALYSIS_GUIDE.md`](../docs/STUDY_ANALYSIS_GUIDE.md).

This directory is kept because project-root detection in the validated code
expects a `scripts/` directory. Historical Phase 2b and R11 recovery scripts
remain in the internal research repository; they are not collaborator entry points.
