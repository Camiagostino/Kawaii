# Kawaii study documentation

Start with the root [`README.md`](../README.md) for installation, supported analysis commands and the expected repository layout.

For running or reviewing Kawaii Session 2 EEG and behavioural analyses, read [`STUDY_ANALYSIS_GUIDE.md`](STUDY_ANALYSIS_GUIDE.md). It explains input identities, analysis stages, local configuration and output boundaries.

The local development checkout may also contain extensive historical scientific reviews, audit records and investigator working notes. Those records are retained for traceability but **are not required reading to operate the study's EEG/behavioural analysis scripts**, and not all are intended for collaborator distribution.

For acquisition/schedule script information, see [`matlab/README_SESSION2_recognition_task.md`](../matlab/README_SESSION2_recognition_task.md).
